# Home Game Settlement

An offline settlement calculator for home poker games — enter each player's
buy-in and cash-out, get the minimum set of payments needed to settle up
(or route everything through a designated "bank"), plus saved game history,
insights, and running standings across sessions.

No backend, no login — everything runs client-side and stores history in
the browser's local storage. Opening this page from a different browser or
device starts a separate history; nothing syncs between them.

Originally built as a personal tool inspired by the HG Poker app.
